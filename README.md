# Car Wash Booking System

Lab 3 - C# (.NET) WinForms desktop application with a SQLite database, built with the MVC pattern.

Student: HIRWA Marcellin (26936)

## Structure

- `Models` - data classes
- `Views` - Windows Forms screens
- `Controllers` - business rules and validation
- `Data` - database access (SQLite)
- `Helpers` - password hashing, validation, session, report export

## Run

Open `CarWashBookingSystem.sln` in Visual Studio 2022 and press F5, or run:

```
dotnet run --project CarWashBookingSystem
```

The database file `carwash.db` is created automatically on first run.

Default administrator: `admin@carwash.com` / `Admin@123`
